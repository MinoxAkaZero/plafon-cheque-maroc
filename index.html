Supprimer définitivement votre compte cloud ?

Cette action supprimera définitivement votre compte d’authentification ainsi que toutes vos copies sauvegardées dans le cloud (chèques, clients, photos et paramètres). Vos données enregistrées localement sur cet appareil resteront intactes.

Clé de récupération du cloud chiffré

Si vous perdez cette clé et tous vos appareils, vos données cloud ne pourront pas être récupérées.
