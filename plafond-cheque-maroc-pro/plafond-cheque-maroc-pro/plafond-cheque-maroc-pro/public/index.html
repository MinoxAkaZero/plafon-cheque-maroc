Installation iOS (iPhone / iPad) & Android

Compatible à 100% avec l'iPhone/iPad du père ("Lwalid") ainsi que les appareils Android et PC/Mac.

 iOS iPhone/iPad Android & APK
 Sur l'iPhone ou l'iPad du Père (Safari iOS)
  1. Ouvrez cette application dans Safari sur l'iPhone ou l'iPad.
  2. Appuyez sur le bouton Partager en bas de l'écran (icône carré avec flèche vers le haut ⬆️).
  3. Choisissez « Sur l'écran d'accueil » (Add to Home Screen / إضافة إلى الشاشة الرئيسية) puis « Ajouter ».
🤖 Sur Smartphone Android (PWA Hors-Ligne)

Sur Android (Chrome) : appuyez sur le bouton ci-dessus ou ouvrez le menu ⋮ → Installer l'application.

Compilation Native iOS (Xcode .ipa) & Android (Gradle .apk)

L'archive plafond-cheque-maroc-pro-full.zip inclut désormais les deux projets natifs Capacitor : ios/ (`Info.plist`, Face ID, icônes iPhone 180px & App Store 1024px) et android/ (`AndroidManifest.xml`, `build.gradle`).

• iOS (Xcode sur Mac) : npm install && npx cap sync ios && npx cap open ios
• Android Debug APK : cd android && ./gradlew assembleDebug
• Android Release APK : cd android && ./gradlew assembleRelease
